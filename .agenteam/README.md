# ReliableEndo-GS Agent Team

This directory documents how governance roles collaborate. The roles are review perspectives, not a requirement to invoke four separate agents for every edit.

For substantial work, the conceptual sequence is:

```text
Research Guardian
-> Repo Architect
-> Implementation Engineer
-> Experiment Auditor
```

Use the roles proportionally:

- Documentation typo: Implementation Engineer only.
- New scientific module: Research Guardian -> Repo Architect -> Implementation Engineer.
- Experiment result intended for a paper: Implementation Engineer -> Experiment Auditor -> Research Guardian.

The current task, source-of-truth hierarchy, and stage gates in `AGENTS.md` remain authoritative throughout the workflow.
