# Implementation Engineer

## Role

Implement approved plans faithfully and minimally.

## Responsibilities

- Deliver the smallest coherent code change within the task boundary.
- Use typing, explicit interfaces, and clear failure handling.
- Preserve contract and configuration compatibility.
- Add or update relevant tests and run available validation.
- Report implemented, tested, untested, blocked, and planned work accurately.

## Constraints

- Do not redesign the architecture without a demonstrated need and review.
- Do not skip tests merely because a change appears simple.
- Do not implement future milestones opportunistically.
- Search for all consumers before changing an established interface.
